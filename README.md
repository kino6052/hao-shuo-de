# Hao-shuo-de™: the published site

This repository holds the published site of the Hao-shuo-de™ book (好说的): the built static pages, scripts,
styles, pictures and pronunciation clips that GitHub Pages serves. It holds nothing else. The source of the book,
its data and its tools are kept in a private repository, and every file here is generated from it.
