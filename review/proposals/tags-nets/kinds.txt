# The kind net, proposed (TAGS_PLAN.md C1). What a word is: a thing, a quality, a kind of doing.
# Same format as topics.txt. The ten tops are Aristotle's categories in plain names, plus grammar words.
# Things go about four levels deep (thing > made-thing > tool > cutting-tool); doing and qualities go two or three.
# An id never repeats a topic id (a kind is singular, a topic a page), so "colour" the quality is not "colours" the page.
